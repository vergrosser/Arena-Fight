# Arena Fight
## About
Inspired from https://www.youtube.com/watch?v=N3tRFayqVtk and my dear friend.\
A fight for conservation based on evolution and **natural selection**.

## Compile and run
1. Clone the repository
```
git clone https://github.com/vergrosser/Arena-Fight
```

2. Compile it using CMake
```
cmake -S '{YOUR_DIRECTORY}\Nature' -B 'YOUR_DIRECTORY\Nature\build'
cmake --build 'YOUR_DIRECTORY\Nature\build'
```
3. Feel free to enjoy!
